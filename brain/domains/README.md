# Domain Packs

Domain Packs hold **all domain-specific knowledge**: concepts, validation rules, question patterns, document expectations, interpretation.

Hive Core loads packs; it does not hardcode domain vocabulary.

Each domain file describes intent only until a pack is implemented and certified.
