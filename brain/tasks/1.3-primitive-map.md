## Map
- **P1** One exported constant, `PACK_PRIMITIVE_MAP`, keyed by the 18 names: arithmetic, as_of_value, change_over_time, compose_governing_with_amendments, coverage, date_relationships, identifier_link, none_answer_vs_records, party_relation, referenced_not_provided, request_response_pairing, requirement_coverage, restatement_agreement, series_continuity, series_over_time, stated_vs_observed, threshold, window_filter.
- **P2** Entry shape: `{ kind: "check" | "selector" | "match", status: "implemented" | "partial" | "planned", runsAs?: string, mode?: string, gap?: string, evidence?: string }`.
  - `check` produces findings; `selector` filters what a check sees (dates, windows, thresholds); `match` links things (step 3).
- **P3** `implemented` and `partial` require `runsAs` (the exported core function name) and `evidence` (`file:line` of that function).
- **P4** `partial` and `planned` require `gap`: one sentence saying what is missing.
- **P5** Lives in the types-only subpath (`@hiveforyou/domain-packs/packs-v2/...`) so `engine/core` can import it with no fs or yaml.
