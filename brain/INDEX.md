## Foundational laws

1. **Engine 1:** Model proposes. Pack defines. Code validates. Professional decides. **Engine 2:** Evidence provides reality. Model studies and proposes. Code validates structure and provenance. Canonical truth drives both views.
2. **No chip → no claim.**
3. **No validated claim → no factual representation.**
4. Domain knowledge → **Domain Packs**, not Hive Core.
5. Customer and Pro share validated canonical truth.
6. **Persist intelligence**; do not re-call models for navigation/reopen/unlock alone.
7. Evidence determines truth; user intent guides emphasis only.
8. Questions and answers are first-class, versioned data.
9. Processing runs and study contexts are versioned/auditable.
10. Production → learning candidates only; no silent pack mutation.
11. No second truth layer outside the canonical model.
